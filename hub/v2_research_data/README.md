# Ordivo v2 research data (private)

**Status:** controlled research metadata and source-specific artifacts for `blackOrder/Ordivo-v2-research-data`. This is not a public dataset release. It must not be confused with the public, synthetic Ordivo v1 dataset or its CC BY 4.0 license. The repository is private at commit `58d0b26d558278ab49f4c0769b44ed928d44204c`. Swissmetro, ESCI and Expedia processed source folders have completed file-level integrity readback. No SUSHI records belong here.

## Episode and split contract

The canonical schema is `ordivo-behavioral-v1`. Each episode has a namespaced `episode_id`, `source`, `task_type`, `group_id`, task context and declared criteria/constraints/preferences, complete alternatives with typed features and availability, a task-matching supervision discriminant, separate exposure, and provenance. The predictor projection permits only source-specific context and alternative-feature allowlists plus declared decision inputs. Supervision, exposure, provenance, source/group IDs, and row order never become predictor features. Candidate IDs remain keys mapped to aliases in prompts. Missing values and unknown preference weights remain explicit; unavailable candidates remain in the group and are masked.

Each source has four **disjoint** frozen roles: train, model-selection validation, calibration, final test. A calibrator may fit only calibration groups; final test is not used for model, feature, prompt, or threshold selection. Preserve complete source-specific split units and record raw/selected/omitted/retained counts, group overlap, split file hashes, source hashes, candidate-pool scope, judgment/target policy, and exclusions. A source-sampled judged candidate pool is not a full retrieval universe. Do not map unjudged candidates to grade zero.

Swissmetro and ESCI are retained under `sources/20261019T030009Z/{swissmetro,esci}/`, each with four split JSONLs, `manifest.json`, `acquisition.json`, and `source_notice.json` (14 files total, 1,579,958,456 bytes). Four large files matched LFS SHA-256 and byte size against the remote source; ten smaller files matched forced-download SHA-256. The sanitized retention manifest SHA-256 is `7294ae44ebbc38e0b0438edf02569d147b5d799143c09425068ce9c2ee8075b0`. The source notices are present in these private folders. For any later run, use `runs/<run-id>/artifact_manifest.json` as the file-level index only after actual upload and remote readback. It should state the executed code commit and archive hash, source URL/revision/file hash, applicable source terms or notice filename, source manifest SHA-256, all four split file hashes and counts, split/target/judgment/candidate-pool policies, each stored artifact path/byte size/SHA-256, and a distribution classification. A missing field stays `pending`; no placeholder is a real checksum. Keep source notices next to the relevant source artifact, and list them in the manifest. Expedia is retained under `sources/20261019T030009Z/expedia/`: `full/` has four grouped splits, manifest, acquisition receipt and source notice; `bounded-79da/` has four sampled splits, manifest, sampling receipt and sampling config. These 14 files total 2,655,258,844 bytes; provider LFS SHA-256/size or private forced-download readback matched every file. The sanitized retention-manifest SHA-256 is `b9fa9e0dc09a7a066eab42c2d9ce660b3ba5e03a42aa64a0b77987e5465542e7`, at private Hub commit `58d0b26d558278ab49f4c0769b44ed928d44204c`. Original raw source archives and SUSHI records are not part of these uploads.

The preliminary model pilot used exact source commit `854de0877c8e7e380b7353a578e95ba9865d4e25`, config SHA-256 `c152e64d839082531d4ece9e66d330fa35ffddfbc442685742b9fd171de5462b`, and the Swissmetro/ESCI manifests above. It selected at most 1,000 training and 100 validation units per source; ESCI prompt overflow excluded 325/1,000 selected training and 29/100 selected validation groups from neural loss. This is an explicit subset, not complete-corpus neural coverage or held-out efficacy. A bounded paired neural probe has now measured negative/mixed results: adapted Swissmetro accuracy 0.66 versus base 0.68 on 450 selected held-out scenarios, and adapted ESCI NDCG@10 0.752276 versus base 0.778290 on 27 of 50 selected held-out queries, with 23 prompt overflows. See the [sanitized aggregate](https://github.com/Krishna2709/ordivo/blob/1955a2ced9fa44cb71e5bee5e19f3002fe522f67/reports/runs/v2-neural-heldout-20261019/aggregate.json). Protected release-test and transfer results remain pending. Classical aggregate results have separate exact run receipts in the project evidence report; they are not adapter predictions.
