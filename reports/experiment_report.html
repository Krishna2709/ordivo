The experiment

The task is single-choice winner prediction. An exact numerical solver creates a teacher label from an alternatives-by-criteria matrix, criterion weights and directions, and a named MCDM method. The model sees that decision state and must select the winning option alias.

Decision episode

3–8 alternatives, 2–6 criteria, min/max directions and weights.

Exact solver

Deterministic float64 COPRAS, WASPAS, VIKOR or TOPSIS scores.

d1 prompt

Method, parameters, full-precision values and candidate aliases A–Z.

LoRA update

Completion-only loss on the correct answer alias plus EOS.

Choice readout

Restricted option probabilities; argmax compared with the exact teacher.

Dataset

Synthetic MCDM Episodes v1 contains 1,000 reproducible, non-personal examples. It tests mathematical imitation under controlled scenario shifts. It contains no hotel bookings, procurement records or human preference labels.

Every episode stores the method, parameters, weights, directions, matrix, ordered tie groups, raw solver scores and a nullable winner. Nonunique outcomes remain available for analysis but are excluded from single-choice training. Positive-valued inputs are required for COPRAS and WASPAS.

Four teachers

Each method answers a different mathematical question. Their scores cannot be compared across methods, and adding an alternative can change normalizers, ideals and rankings. Use the tabs to inspect each solver contract.

COPRAS

Balances the sum of weighted benefit criteria with an inverse proportional cost term.

Higher Q is better.

Normalize each column by its sum → weight → split benefit P and cost C
Qᵢ = Pᵢ + ΣC / (Cᵢ · Σ(1/C))

Failures are evidence

v2 passed its stated acceptance contract, but “passed” does not mean every numerical discrepancy vanished. The report keeps environment failures, loader differences, reload drift and calibration risk visible beside the improved accuracy.

Resolved Optional torchao broke the measured stack

The notebook's open-ended torchao>0.16 selected 0.18.0, which failed with Torch 2.9.1. Version 0.15 imported, but PEFT 0.21.2 required 0.16 or newer during LoRA injection.

Resolution: omit optional torchao and use the successful non-quantized BF16 path. TRL 1.15's warmup API was also mapped from the configured 0.05 fraction.

Accepted with bounded drift Reload is decision-equivalent

All 16 decisions survived save/reload. The maximum probability delta was 0.02147 and the mean was 0.00111, within the declared 0.05 tolerance. Repeated inference and two independent fresh reloads matched exactly.

argmax agreement = 16 / 16
max |Δ probability| = 0.021474
fresh reload vs reload = 0.000000

Boundary: exact saved-versus-live probability parity is still false. The release claim is decision equivalence within tolerance.

Documented limitation Two loader paths were not identical

The custom d1 wrapper and the standard image-text loader agreed on 7 of 8 base argmax decisions. Their maximum probability delta was 0.01562.

Implication: the evaluation path itself can move a borderline decision. The release comparisons use one pinned standard path; custom-wrapper equivalence is not claimed.

Open model limitation Accuracy improved faster than calibration

On the 87-example test, Brier score improved from 0.781 to 0.623, but 10-bin ECE rose from 0.118 to 0.239. Several remaining errors are confident; one recorded TOPSIS regression assigns 93.7% to the wrong option.

Implication: report probabilities as experimental scores, not calibrated confidence. Temperature scaling requires a separate validation set and evaluation.

What remains

The release is a reproducible M3 result, not the end of the research question. The next experiment should test robustness and calibration without using the published test split for model selection.

Calibrate on validation

Fit temperature scaling on a frozen validation set and report ECE, Brier and accuracy without changing the winner rule. Test whether confidence becomes more reliable on the untouched test set.

Probe invariances

Measure alternative-order permutations, positive scale changes, criterion-direction flips and candidate-set changes at episode level. Compare every learned decision with the exact solver's documented invariant boundary.

Establish uncertainty

Repeat the selected configuration across at least three seeds and compare against numerical Set Transformer and LightGBM controls. Report confidence intervals by method, scenario family and candidate count.

Interpretation boundary: exact solvers remain the correct tool for computing COPRAS, WASPAS, VIKOR and TOPSIS. This adapter demonstrates learnable imitation under synthetic scenario shift. It does not establish human preference modeling, full-ranking ability or arithmetic superiority over the teachers.
